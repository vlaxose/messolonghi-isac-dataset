# Messolonghi ISAC Dataset

Range-Doppler dataset for decentralized and federated learning: labelled bistatic ISAC radar patches (drone, hovering drone, bird, clutter) from 10 real mobile masts in Messolonghi, Greece, simulated by ray tracing (Sionna RT) on a 3D model of the town.

Description page: https://vlaxose.github.io/messolonghi-isac-dataset/
